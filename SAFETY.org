*Status: accepted by the owner on 2026-10-19*, with findings F1-F3

* What this is
What this configuration may and may not do with the owner's notes,
files, data and accounts -- written to be judged without reading the
code.  For each rule: what guards it in the code today, and which
automatic test shows it holds, or "none yet".  A rule without a test is
a promise in a comment, not a checked fact.

A test counts only when it has been shown to fail with the safeguard
taken out (recorded in CHANGELOG.md).  A rule of several clauses is
marked *partly* tested, with the clauses tested and those not: a test
file's name next to a whole rule claimed more than it showed (audit of
2026-10-20).  Tests run at every push
(=.github/workflows/checks.yml=) and by hand with =bash hooks/check-all=.

How this list was made: by searching the code (2026-10-19) for what
publishes, deletes, moves, reaches the network and runs programs, and
reading each place found.  A place the search patterns missed is not
here; the independent review (last section) is the check on that.

* Findings
- *F1* (done 2026-10-19y): a note git does not track was deleted for
  good (=delete-file=).  It goes to the trash now.  A tracked one was
  removed with =git rm -f=, which loses what was written since the last
  commit; since 2026-10-24b it goes to the trash as well (outside
  audits, decided by the owner).
- *F2* (done 2026-10-19y): the upload question said where to, not that
  the upload makes the folder there an exact copy of the build (=rsync
  --delete=).  It says so now, and a =:remote= that is a home folder or
  the root is refused.  The rights of the user rsync logs in as limit
  what it can delete -- a deploy user owning only the site's folder
  limits the damage to that folder -- but not within that user's own
  home, which is where an empty path (=user@server:=) points.
- *F3* (done 2026-10-19y): a theme installed with =git clone= took
  whatever its repository held that day.  PaperMod is pinned to its
  newest commit of 2026-10-19 (=969bebdc5600=), checked out after the
  clone; an installed theme at another commit is reported, not
  changed.
- *F4* (open): packages are not pinned (no lockfile), so a changed or
  compromised package would arrive with the next install.  A decision
  of its own (BACKLOG, /Start-up/ and /Packages pinned/).
