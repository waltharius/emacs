#+title: Test plan
#+startup: overview

Manual tests of the configuration on a live machine, with the real
notes.  Part A covers what touches notes and their folders; a failure
there can lose or misplace writing.  Part B covers appearance and
interface; a failure there is annoying, not harmful.  Tick boxes with
=C-c C-c=; the cookies count progress.  Record anything unexpected under
[[*Findings][Findings]] with the date, the machine and what was done.

Run Part A against a *copy* of the notes (=~/notes2=, section A1), so
that a bug costs a copy.  Where a check reads "on notes2", it means the
root is =~/notes2= at that moment.

* Preparation [0/6]
- [ ] =git -C ~/notes status= clean and pushed; same for =~/.emacs.d=.
- [ ] A btrfs snapshot of the home subvolume taken today.
- [ ] All patches applied (=git log --oneline -15= in =~/.emacs.d=);
      restart; =*Messages*= has no error or backtrace.
- [ ] =M-x emacs-init-time= noted, on Azazel and on baal, for later
      comparison.
- [ ] =C-c n ,= opens the MyPKS tree with six areas.
- [ ] =hooks/lint.py= and =hooks/parens.el= pass (=git commit= of a
      trivial change, or run them by hand).

* Part A -- notes and their folders
** A1. Moving the notes root (copy only) [0/12]
- [ ] =C-c n ,= → Notes and silos → =my-notes-dir= = =~/notes2/= → Apply
      and Save.  Echo area: takes effect after a restart.
- [ ] Restart.  Question with three answers: copy / skip / ask later.
      Answer /ask me next time/: Emacs runs on =~/notes=, nothing
      created at =~/notes2=.
- [ ] Restart, answer /copy/.  Report buffer =*MyPKS notes move*=:
      identical file count and bytes; "old root untouched".
- [ ] The question about the git history appears; answer /turn push
      off/.  =C-h v my/auto-commit-push= → nil, saved.
- [ ] Report lists saved settings still pointing at =~/notes= (habits
      file in =my/tasks-extra-agenda-files=).  Fix it in =C-c n ,=, then
      =C-c a= shows the habits again.
- [ ] =df -h ~= before and after the copy: on btrfs the copy is a
      reflink and takes almost no space.
- [ ] =C-c n c n=, any title: the file is created under =~/notes2/=.
- [ ] =git -C ~/notes log -1= and =status= unchanged after working on
      notes2 for a while (auto-commit runs in notes2, no push).
- [ ] Switch back: =my-notes-dir= = =~/notes/=, restart.  Question
      "both hold notes"; answer /ask me next time/ → still notes2;
      restart, answer /switch/ → notes.  Nothing copied either way.
- [ ] =M-x my/notes-delete-old-root= → "Disabled".  Leave it disabled.
- [ ] /Skip/ path with a throw-away root (=~/notes3/=): silo folders
      created empty, report says to move files by hand.  Delete
      =~/notes3= by hand afterwards and set the root back.
- [ ] Refusals: a root inside the current one (=~/notes/sub/=) and a
      non-empty unrelated folder are refused with a report; Emacs keeps
      the old root.

** A2. Silo registry [0/10]
- [ ] =C-c n ,= → =my/silos=: three entries (journal, pks, docu) with
      roles journal / notes / docs.
- [ ] Add silo =test= (=:directory "test/"=), restart: folder created;
      =C-c n c n= offers it in /Save in/ (pks first).
- [ ] A note in =test= appears in =C-c n f n=, in link insertion and in

- [ ] Set =:disabled= on =test=, restart: absent from /Save in/, from
      =C-c n f n=, link prompts and backlinks; file still on disk and in

- [ ] A link to that note from another note does not open while
      disabled, and opens again after clearing =:disabled=.
- [ ] Delete the =test= entry instead of disabling it, restart: about 3 s
      later =*Messages*= names =test= as a folder with notes but no silo;

- [ ] Inbox notes stay hidden from =C-c n f n= (shared exclusion list).
- [ ] =C-h v denote-excluded-directories-regexp= lists inbox,
      inbox-odrzucone and any disabled silo, nothing else.
- [ ] Statistics (=C-c n f s=) largest-notes section covers the enabled
      silos.
- [ ] Remove the =test= folder by hand when done.

** A3. Deletion questions [0/8]
- [ ] =C-c n d d= on a scratch note → asked; /no/ keeps the file.
- [ ] /yes/ → deleted (=git rm= when tracked); attachments question when

- [ ] Delete a scratch note: no question; =*Messages*= records

- [ ] =C-c n d != again → questions back, =!DEL= gone.
- [ ] Switch off for the session, restart → questions are back.
- [ ] =C-c n ,= → =my/confirm-deletion= = never → =!DEL= after restart

- [ ] =C-c n d c= (change silo) onto a note with the same title →

* Part B -- appearance and interface
** B1. Writing mode [0/6]
- [ ] =C-c n v w= first activation after a fresh start: time it on
      Azazel and on baal.  Expected: immediate.
- [ ] Mode line: =W= right after the word and page count; gone after
      turning the mode off; messages without emoji.
- [ ] Typing keeps the line at the middle; scrolling and clicking are
      not disturbed.
- [ ] In a note with large images the line still holds its place;
      =C-c u i= hides the images.

      =M-: (benchmark-run 1 (progn (insert "✍") (redisplay t)))= in
      =*scratch*=.  Seconds there mean font fallback for symbols is the
      cost; the emoji in other modules' messages are then worth
      replacing (BACKLOG).
- [ ] Positions: =M-x my/set-writing-position-upper= / =lower= /
